🗄️ DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════
1. meals                       - All meal records (10 columns)
   - Indexes: chat_id, eaten_at, deleted
   - Soft delete support

2. meals_draft                 - FSM state storage (11 columns)
   - Unique: (chat_id, message_id)
   - Status: await_dish → await_alt/await_weight → done

3. digest                      - Daily summaries (11 columns)
   - Unique: (chat_id, for_date)
   - JSON fields for meals list

4. chat_logs                   - AI conversation history (9 columns)
   - Indexes: (chat_id, session_id), created_at
   - Role-based: user, assistant, system

🚀 QUICK DEPLOYMENT (VPS)
═══════════════════════════════════════════════════════════════════════════
Time Required: 5 minutes

Step 1 (Local):
  rsync -avz nutrition_bot/ root@VPS_IP:/opt/nutrition_bot/

Step 2 (VPS):
  cd /opt/nutrition_bot
  ./DEPLOY_COMMANDS.sh

Step 3:
  Test bot in Telegram: /start
